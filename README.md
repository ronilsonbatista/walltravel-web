# WallTravel Web - Redesenho Editorial

Este repositório contém o código-fonte do redesenho completo do site da **WallTravel**, uma assessoria premium de viagens sob medida.

A nova identidade visual foi construída com um tema claro, minimalista e sofisticado (estilo revista de viagem e hotel boutique), utilizando:
*   Fundo off-white quente (`#F4F1E8`) e areia (`#EFEBDD`).
*   Tipografias `Faculty Glyphic` (títulos) e `Rubik` (corpo).
*   Slideshow com autoplay, efeito Ken Burns e barra de progresso no Hero.
*   Grid editorial responsivo para a seção de destinos.
*   Cards bipartidos sofisticados na seção de serviços.

## Tecnologia Utilizada
*   HTML5
*   CSS3 Vanilla (Design tokens e Scroll-driven animations)
*   JavaScript ES6+
*   Vite (Bundler e Dev Server)

## Como Rodar Localmente

1.  Instale as dependências:
    ```bash
    npm install
    ```

2.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

3.  Gere a versão de produção (build):
    ```bash
    npm run build
    ```
